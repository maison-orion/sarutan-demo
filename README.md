# さる単 デモ

英語学習者の、英語学習者による、英語学習者のための単語帳「さる単」の動く試作です。

**開く**: https://maison-orion.github.io/sarutan-demo/ （スマホで開くと全画面のアプリとして動きます）

## 画面

| 画面 | 動き |
|---|---|
| Test | カードをタップで意味。右＝もう覚えた／上＝もう少しで覚えられそう／左＝全然覚えてない／下＝あとで回す。「1つ戻す」あり。結果は端末内に保存 |
| Words | 単語一覧（A→Z・動画で頻出順・検索）。タップで単語ページ |
| 単語ページ | 動画をタップ→光の軌跡→動画拡大・再生→関連語チップ→単語へ収束→ネットワーク図＋Nuance＋覚え方。ノードをタップで発音。最後に「全然／もう少し／覚えた」でMy単語帳へ。左右スワイプで前後の単語 |
| Profile | My単語帳の3ラベル、通知、解説の方言（標準語／関西弁／名古屋弁）。方言は単語ページの「覚え方」に効く |

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ビルド成果物。これ1つで動く（画像・動画は中に埋め込み済み・約1.7MB） |
| `index.template.html` | 編集はここ。CSS／データ／ロジック全部入り。画像は `{{IMG:*}}`、動画は `{{VID:*}}` トークン |
| `tools/build.py` | トークンを data URI に置換して `index.html` と `artifact.html` を出力 |
| `assets/` | 動画枠の静止画6枚（800px）と動画6本（640px・4秒・音声なし） |

```bash
python3 tools/build.py
```

## デモとして割り切っているところ

- 収録は6語（explore／qualified／reliable／silly／afford／genuine）。語彙データは `index.template.html` の `WORDS` に直書き
- 「動画 N回」の頻出回数、クリップの時刻、ユーザー情報はダミー
- 動画枠の映像は AI 生成（静止画＝Seedream 4.5、動画＝Seedance 1.5 Pro）。本番は実際の動画クリップに差し替える前提
- ログイン・課金・通知の実体はなし。仕分け結果は端末の localStorage にだけ保存
